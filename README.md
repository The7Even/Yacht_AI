# ChatGPT를 극한으로 활용해보자. (초심)
이 프로젝트는 ChatGPT Go 요금제를 결제한 후 뽕?을 뽑기 위해 진행해보는 AI 제작 프로젝트입니다.
혹시나 찾아오실 분이 있을진 모르겠지만 오신다면 환영합니다..

Yacht를 AI가 직접 플레이하여 최선의 결과를 얻는 것을 목표로 ChatGPT를 부려먹고 있습니다.
현재까지는 AI 개선 작업중이라(26.8.21 기준) 해봤자 평균 150~170점 정도의 성능을 내고 있습니다.
ChatGPT한테 직접 시켜서 플레이시키니까 대강 180~200점도 내는 걸 보아서는 더 향상시킬 여지가 있다고 판단하여 학습과 알고리즘 개선으로 수정중에 있습니다.

물론 제가 하는건 없습니다. 그 홍X보 처럼요.
