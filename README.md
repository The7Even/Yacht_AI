# ChatGPT를 극한으로 활용해보자. (초심)
이 프로젝트는 ChatGPT Go 요금제를 결제한 후 뽕?을 뽑기 위해 진행해보는 AI 제작 프로젝트입니다.

혹시나 찾아오실 분이 있을진 모르겠지만 오신다면 환영합니다..


Yacht를 AI가 직접 플레이하여 최선의 결과를 얻는 것을 목표로 ChatGPT를 부려먹고 있습니다.

현재까지는 AI 개선 작업중이라(26.8.21 기준) 해봤자 평균 150~170점 정도의 성능을 내고 있습니다.

ChatGPT한테 직접 시켜서 플레이시키니까 대강 180~200점도 내는 걸 보아서는 더 향상시킬 여지가 있다고 판단하여 학습과 알고리즘 개선으로 수정중에 있습니다.

물론 제가 하는건 없습니다. 그 홍X보 처럼요.

8.22 추가)

현재 UI를 다듬고 있습니다. 일단 ai 개선은 좀 힘들것 같아서 150~180점 수준을 유지하면서 UI를 완성하여 일단 게임 구동이 가능한 수준으로 개선 후 다시 AI 개선에 돌입할 예정입니다.

현재 새로 만든 모델이 90\~110점을 만들어 냈으며 이 모델이 150\~180점 수준의 모델을 참고하며 발전할 예정입니다.

나중에 여유가 된다면 딥러닝으로 더 개선할 여지도 있으니 일단은 지켜봅시다.

그리고 여전히 제가 하는건 UI 개선에 대한 아이디어 제공정도밖에 없습니다. 이정도면 홍X보보단 하는게 많네요.

추가로 개발에 사용될 LLM을 ChatGPT에서 Gemini Pro로 바꿀수도 있습니다. Gemini가 Pro 요금제를 학생 대상으로 월 7300원에 모시더라구요. 좋은데?

9.1 추가)

현재 잠시 개발을 쉬어갑니다.

개강한 대학생이 되어 학기 중에 진행하는 인공지능 수업 듣고 직접 딥러닝 실습용으로 사용할 예정입니다.

9.10 추가)

간단하게 20K ~ 50K 정도의 학습을 통하여 발전시키고 있습니다.

현재까지의 성과로는 평균 140점, 최고점 272점을 달성하였으며, 조금 더 개선하여 평균 150점 이상의 모델을 완성시키는 것이 목표입니다.

앞으로의 전체적인 개발은 Gemini Pro가 진행할 듯 싶습니다. 근데 제미나이는 Github와 연동하여 자체 수정이 되지 않아 이 점이 좀 걸리네요.

앞으로 개발에 있어 좀 과도기가 있을 듯 합니다.

그리고 인공지능 모델이 맛탱이가 갔습니다. 한동안은 Ui 작업만 하면서 수업듣고 그걸로 딥러닝해서 AI 강화해보겠습니다..
