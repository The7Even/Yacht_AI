# ChatGPT를 극한으로 활용해보자. (초심)
이 프로젝트는 ChatGPT Go 요금제를 결제한 후 뽕?을 뽑기 위해 진행해보는 AI 제작 프로젝트입니다.

혹시나 찾아오실 분이 있을진 모르겠지만 오신다면 환영합니다..

Yacht를 AI가 직접 플레이하여 최선의 결과를 얻는 것을 목표로 ChatGPT를 부려먹고 있습니다.

현재는 AI 연구와 함께 실제로 사람이 플레이할 수 있는 게임 UI를 만드는 단계로 넘어가고 있습니다.

## GUI Prototype

PySide6 기반의 데스크톱 UI 프로토타입을 추가했습니다.

```bash
pip install -r requirements.txt
python -m app.gui
```

현재 프로토타입에서 확인할 수 있는 기능은 다음과 같습니다.

- 5개 주사위 표시
- 주사위 클릭 HOLD / UNHOLD
- 한 턴 최대 3회 굴리기
- 사용 가능한 카테고리와 현재 점수 미리보기
- 12개 카테고리 점수판
- 상단 63점 기준 35점 보너스 표시
- 플레이어/AI 점수 영역
- 게임 규칙 안내 및 게임 재시작

UI는 기존 `GameEngine`을 직접 사용하므로, 게임 규칙은 콘솔/벤치마크와 동일한 코어 로직을 공유합니다.

현재 AI 턴은 UI 프로토타입 단계에서 자리만 먼저 잡아둔 상태이며, 다음 단계에서 FastEV 등의 기존 전략을 실제 게임 진행과 연결할 예정입니다.
